Intro videos on Jellyfin

Add the plugin repository, install one plugin, and Jellyfin picks the right intro for every movie and episode.

Jellyfin has no built-in setting for intro videos. The Prerolls Max Intros plugin fills the gap: each time a movie or episode starts, it asks Prerolls Max which intro to play. That's how Jellyfin can pick a different intro by genre, age rating, decade, library or person.

What you need

Jellyfin 10.11 or 12, Prerolls Max running, and an administrator account on Jellyfin.

Set it up

  1. Make an API key in Jellyfin

    Sign in as an administrator, open Dashboard, then API Keys, press +, call it Prerolls Max, and copy the key.

  2. Connect Prerolls Max to Jellyfin

    In Prerolls Max, open Media Servers and press Connect Jellyfin. Enter the address you use to open Jellyfin, like http://192.168.1.10:8096, and paste the key. If Prerolls Max runs in Docker, use the computer's network address, not localhost.

  3. Install the plugin

    Easiest: in Jellyfin, open Dashboard, Plugins, Repositories, press +, name it Prerolls Max, and paste the address for your version:

    Jellyfin 12:    https://modernharp.github.io/prerolls-max/jellyfin/manifest.json
Jellyfin 10.11: https://modernharp.github.io/prerolls-max/jellyfin/manifest-10.11.json

    Open Catalog, install Prerolls Max Intros, and restart Jellyfin.

    Or install by hand: Prerolls Max can download the right zip for you, or take Jellyfin 12 or Jellyfin 10.11 from the release. Unzip it into a new folder called PrerollsMax inside Jellyfin's plugins folder (/config/plugins in Docker, /var/lib/jellyfin/plugins on Linux, %LOCALAPPDATA%\jellyfin\plugins on Windows) and restart.

  4. Let Prerolls Max set up the plugin

    Press Set up the plugin for me on the Jellyfin card. Prerolls Max fills in the plugin's settings, including a key of its own. Then play any movie in Jellyfin and press Check now. The card shows Working once the plugin has asked for an intro.

  5. Test it

    On Home, press Start test next to Play a test, then start a movie from the beginning in a web browser. Your intro should play first. Test in a browser before a TV or phone: some apps skip intros until you change a setting. See which apps play intros.

Which Jellyfin apps play intros

AppPlays intros?
Web browser, Jellyfin Media PlayerYes, movies and episodes
Android, Kodi (Jellyfin add-ons)Yes
Android TVMovies only, from the start
Roku (official app)Turn on Cinema Mode. Plays only the first intro.
Swiftfin, Infuse, Jellyfin MPV Shim, Samsung TVNo

In the apps that play intros, Cinema Mode is on to begin with and each device has its own switch. If one device skips intros, check it is still on. Intros never play when you resume a movie.

How the plugin behaves

  • It never holds up playback. It waits at most 3 seconds for Prerolls Max, and intros that aren't downloaded yet keep downloading in the background.
  • It keeps working if Prerolls Max is down, by playing the last list of intros it received.
  • It tidies up after itself: a scheduled task downloads what could play and removes old copies.

Jellyfin questions

Does Jellyfin need a plugin for prerolls?

Yes. Jellyfin has no setting of its own for intro videos. The Prerolls Max Intros plugin asks Prerolls Max which intro to play each time a movie or episode starts.

Which Jellyfin versions work?

Jellyfin 10.11 and Jellyfin 12. Prerolls Max picks the right plugin for your version.

Can Jellyfin play intros before TV episodes?

Yes. They play before the episode you pick, not between episodes that follow each other on their own. You can also limit them to the first episode of a binge.

Why does my Roku play only the first intro?

The official Jellyfin app on Roku plays only the first intro. Combine several intros into one video and it plays them all.

Will it slow down playback?

No. The plugin waits at most 3 seconds for Prerolls Max, downloads intros in the background, and keeps playing the last list it received if Prerolls Max is down.
