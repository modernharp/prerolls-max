Even with everything set up right, some apps skip intros. This list was checked in November 2026. If your app isn't listed, test in a web browser first: if the intro plays there, the app is the reason.

Plex#

AppPlays intros?
Web browser (app.plex.tv), Plex desktop appYes
Roku, smart TVsUsually
2026 apps for Apple TV, iPhone, iPad, Android TV, Fire TV and ShieldOnly after a change: in the app's settings, set Cinema trailers to play before movies to 1
Casting, DLNA, Plexamp, downloads, InfuseNo

Plex plays intros before movies only, and the same intro list is used for everyone.

Jellyfin (with the Prerolls Max plugin)#

AppPlays intros?
Web browser, Jellyfin Media PlayerYes, movies and episodes
AndroidYes
Android TVMovies only, from the start
Roku (official app)Turn on Cinema Mode. Plays only the first intro, so combine several into one.
Kodi (Jellyfin add-ons)Yes
Swiftfin, Infuse, Jellyfin MPV ShimNo
Samsung TVNo

Emby (needs Emby Premiere)#

AppPlays intros?
Web browser, phone and tablet appsYes, with Cinema Intros on in the app
Android TV, Fire TVMovies only
RokuTurn on Cinema Intros in the app. It can be unreliable.
Samsung TVOften not. Some show "No compatible streams"; an H.264 MP4 intro sometimes helps.
InfuseNo

On every server#

  • Intros play only when you start from the beginning, never when you resume.
  • No intro plays between episodes that play on their own, one after another.

Home warns you when it spots an app that skipped an intro. See Missed-intro check. Not sure what applies to you? Try the troubleshooter.
