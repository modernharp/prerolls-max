Intro videos on Emby

One plugin file, Emby Premiere, and Prerolls Max chooses the intro for every play.

Emby plays intros through Cinema Intros, a feature of Emby Premiere. The Prerolls Max Intros plugin tells Emby which intro to play each time something starts, so you can use schedules and rules instead of one fixed list.

What you need

Emby 4.9 or later with Emby Premiere, Prerolls Max running, and an administrator account on Emby.

Set it up

  1. Make an API key in Emby

    Sign in as an administrator, open Settings, then API Keys, press New API Key, call it Prerolls Max, and copy the key.

  2. Connect Prerolls Max to Emby

    In Prerolls Max, open Media Servers and press Connect Emby. Enter the address you use to open Emby, like http://192.168.1.10:8096, and paste the key. If Prerolls Max runs in Docker, use the computer's network address, not localhost.

  3. Install the plugin

    Download the Emby plugin from the release, or let Prerolls Max download it for you. Unzip it and copy PrerollsMax.Emby.dll straight into Emby's plugins folder, not into a folder of its own: /config/plugins in Docker, /var/lib/emby/plugins on Linux, %APPDATA%\Emby-Server\programdata\plugins on Windows. Restart Emby.

  4. Let Prerolls Max set up the plugin

    Press Set up the plugin for me on the Emby card. If Emby runs in Docker or on another computer, first change the address to this computer's network address with numbers, like 192.168.1.10, because Emby's Docker image can't use host.docker.internal. Then play any movie and press Check now.

  5. Turn on Cinema Intros

    Emby only plays intros when three things are true: you have Emby Premiere, Cinema Intros is on in the server settings (turn on intros for episodes too if you want them before TV shows), and Cinema Intros is on in each Emby app under Settings, then Playback.

  6. Test it

    On Home, press Start test next to Play a test, then start a movie from the beginning in a web browser. Your intro should play first. Test in a browser before a TV or phone: some apps skip intros until you change a setting. See which apps play intros.

Emby questions

Do I need Emby Premiere for prerolls?

Yes. Emby plays intros through its Cinema Intros feature, and that needs Emby Premiere.

Which Emby versions work?

Emby 4.9 and later.

Why isn't a new intro playing straight away?

A brand-new intro can take up to a minute to start playing on Emby, because Emby has to register it first. Until then the movie plays without that intro.

Why do some Emby apps skip intros?

Each Emby app has its own Cinema Intros switch under Settings, Playback, and the Roku app has it off to begin with. Samsung TV apps often don't play intros at all. Which apps play intros.
