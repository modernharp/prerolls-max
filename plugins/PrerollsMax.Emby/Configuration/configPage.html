Prerolls Max Intros

Plays the intro videos Prerolls Max chooses before movies and episodes. Prerolls Max can fill these in for you: in Prerolls Max, open Media Servers and press "Set up the plugin for me". Emby plays intros only with Emby Premiere and with Cinema Intros turned on in each app (Settings, Playback).

The address this Emby server uses to reach Prerolls Max. Not "localhost" if they run in separate containers.
From Prerolls Max: Settings, Advanced, API keys. Needed when login is on there.

When intros play

If Prerolls Max takes longer, playback starts with the intros it chose last time (or none).
Used by "first episode only" in Prerolls Max.
