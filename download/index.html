Docker

The image runs on 64-bit Intel and AMD machines and on ARM (Raspberry Pi and similar). It runs as an ordinary user, not as root. PUID and PGID should be the user and group that own your intro folder. Run id to see yours; on Unraid they are 99 and 100.

docker run -d --name prerollsmax --restart unless-stopped -p 9393:9393 \
  -e TZ=Europe/London -e PUID=1000 -e PGID=1000 \
  -v prerollsmax-data:/data \
  -v /path/to/your/prerolls:/data/prerolls \
  ghcr.io/modernharp/prerolls-max:latest

Then open http://<your-computer>:9393 and make an account. Prefer Compose? Download docker-compose.yml, change the intro folder, and run docker compose up -d.

Image tags: latest follows the newest stable release, 1.0.0 stays on this version, and edge follows the main branch.

docker pull ghcr.io/modernharp/prerolls-max:latest

If Plex runs in Docker too, give it the same intro folder. If it sees the folder under a different path, read folder mapping.

Jellyfin plugin repository

In Jellyfin, open Dashboard, Plugins, Repositories, press +, name it Prerolls Max and paste the address for your version. Then open Catalog, install Prerolls Max Intros, and restart Jellyfin.

Check your download

Every file is listed with its SHA-256 checksum in SHA256SUMS.txt on the release. To check a file on Windows, run this in PowerShell and compare the result with the line for that file:

Get-FileHash .\PrerollsMax_Installer_v1.0.0.exe -Algorithm SHA256

On Linux or macOS, put the file next to SHA256SUMS.txt and run sha256sum -c SHA256SUMS.txt --ignore-missing.

The Windows installer is not signed with a paid code-signing certificate, so Windows SmartScreen may say it protected your PC. Choose More info, then Run anyway, once you've compared the checksum.

What you need

  • Plex: any recent Plex Media Server. No Plex Pass.
  • Jellyfin: 10.11 or 12, with the Prerolls Max plugin.
  • Emby: 4.9 or later, with the plugin and Emby Premiere.
  • FFmpeg for checking and fixing videos. The Windows installer can add it, and the Docker image has it.
