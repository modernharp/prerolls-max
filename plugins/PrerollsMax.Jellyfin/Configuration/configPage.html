Prerolls Max Intros

Plays the intro videos Prerolls Max chooses before movies and episodes. Prerolls Max can fill these in for you: in Prerolls Max, open Media Servers and press "Set up the plugin for me".

The address this Jellyfin server uses to reach Prerolls Max. Not "localhost" if they run in separate containers.
From Prerolls Max: Settings, Advanced, API keys. Needed when login is on there.

When intros play

If Prerolls Max takes longer, the movie starts with the intros it chose last time (or none). Intros still downloading play from the next playback on.
Used by "first episode only" in Prerolls Max.
More settings
Set both to play intros straight from a shared folder. Otherwise they're downloaded.
